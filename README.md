# Angular Single Page

Proyecto de clases, creando una single Page con Angular

## Instrucciones
- Verificar si tiene node.js instalado: `node -v`
- Instalar dependencias seguras(proteger el proyecto de ataques conocidos en el ecosistema npm con paquetes comprometidos que ejecutan scripts maliciosos durante la instalación): `npm ci --ignore-scripts`
- Revisar vulnerabilidades conocidas en las dependencias: `npm audit`
- Corregir automáticamente lo que se pueda sin romper compatibilidad: `npm audit fix`
- Correr el servidor de desarrollo usando la versión local del proyecto (sin instalar Angular CLI global): `npx ng serve`
